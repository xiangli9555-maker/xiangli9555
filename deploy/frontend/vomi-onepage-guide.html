VOMI · VO MANAGER · ONE PAGE GUIDE

一张图看懂 Vomi 怎么运转

四种角色，共用一条链路：需求进入系统，台词与角色逐步明确，档期完成后进入录制与交付。
一句话Vomi 不替代 TAPD 和腾讯在线台词表；它把版本节点、需求状态、声优信息与录制档期串成一个可追踪的工作台。

主流程 · 从需求到交付

先看横向流程，再看下方自己的角色卡

01

需求进入

玩法策划在 TAPD 提交 VO 需求；系统导入后，需求汇总页按版本和 AREA 集中展示。

入口：需求汇总
02

澄清与预估

玩法与文案澄清角色、触发和音画同步；形成声优范围与预估句数。

协作：需求汇总 + 澄清
03

台词协作

每个需求生成一份在线台词表；文案填写角色、台词与必要标记，系统统计实际句数。

载体：腾讯在线台词表
04

选角与排期

音频维护声优信息，按中配／英配安排录制日期、地点和状态，风险预警同步更新。

入口：声优库 + 录制档期
05

录制与交付

按档期完成录制，更新完成状态；所有人通过版本节点和汇总数据查看当前进展。

查看：录制档期 + 版本节点

我的角色 · 我该做什么

玩法

我是提需求的玩法策划

把需求讲清楚，让后续人员能直接执行

从哪进入
TAPD 创建需求，再到“需求汇总”确认是否已进入当前版本。
我要做
确认标题、AREA、创建人和音画同步；参加澄清，说明角色、场景、触发和期望。
系统会做
按版本聚合需求，显示状态与 DDL，并把后续台词表、声优预估和档期串起来。
完成标志：需求已澄清，角色与台词范围明确；后续可在汇总页追踪，不需要重复口头问进度。
文案

我是文案策划

完成预估与台词，让数量、角色和版本可追踪

从哪进入
在“需求汇总”筛选自己的需求，从台词表图标打开该需求在线表格。
我要做
填写声优类型、预估句数、游戏角色、中文台词和音画同步；按 DDL 完成交接。
系统会做
自动统计实际句数与偏差，校验角色；台词锁后把版本总表作为唯一修改口径。
完成标志：台词表角色校验通过，预估与实际差异已处理，锁表后不再直接修改需求分表。
音频

我是音频团队

把角色、声优、档期和录制结果真正落地

从哪进入
先看“版本节点”和“需求汇总”，再进入声优库／录制档期处理执行信息。
我要做
确认声优与选角信息；按中配／英配排日期、地点和状态；发现缺口及时处理风险预警。
系统会做
按需求和角色聚合档期，提示待约与冲突，并把已完成状态回流到全局进度。
完成标志：风险预警归零，所需角色均有明确档期，录制完成后状态和交付信息已更新。
查看

我是浏览网站的人

快速判断当前版本、关键节点和风险

从哪进入
从左侧栏选择发布计划；“需求汇总”看全貌，“版本节点”看时间，“录制档期”看执行。
我要做
使用版本、AREA、状态和语言筛选；点击需求或文档链接查看原始信息。
系统会做
展示真实 API 数据；若使用快照，会明确显示快照时间，不用页面加载时间冒充更新时间。
完成标志：能回答三件事：当前版本做到哪、下一节点是什么、哪里仍有待处理风险。
数据怎么流
TAPD / 发布计划→Vomi API 与数据库→需求汇总→在线台词表 / 声优库 / 档期→进度与交付
状态速读已完成／可执行待处理／临近 DDL风险／需要关注只读／未开始
阅读建议：先看主流程，再只读自己的角色卡；不确定数据是否最新时，优先查看页面上的数据源与快照时间提示。
