# 🚀 Vo Manager · 一键部署命令

## Step 1 · 上传部署包

**要上传的文件**：
```
C:\Users\lycheelli\WorkBuddy\音频-Vo管理\deploy-vo-manager.zip
```
（只 81KB，超快）

**操作**：
1. 打开腾讯云 CVM 控制台 → 进入 CVM `21.130.252.59` 详情页
2. 顶部标签 **「文件上传」**
3. 上传 `deploy-vo-manager.zip` 到 CVM 的 `/root/` 目录（默认就是这个）

## Step 2 · 执行部署（复制粘贴）

顶部标签 **「执行命令」** → 粘贴下面整段 → 点执行

```bash
set -e
cd /root

# 1. 解压（自动处理中文文件名 GBK/UTF-8 兼容）
if [ -f /root/deploy-vo-manager.zip ]; then
  yum install -y unzip 2>/dev/null || dnf install -y unzip 2>/dev/null || true
  # 用 -O CP936 处理 Windows zip 的 GBK 文件名
  rm -rf /root/deploy
  unzip -o -O CP936 /root/deploy-vo-manager.zip -d /root/ 2>/dev/null || unzip -o /root/deploy-vo-manager.zip -d /root/
  echo "✓ 解压完成"
fi

if [ ! -d /root/deploy ]; then
  echo "❌ 未找到 /root/deploy 目录"
  ls -la /root/ | head -20
  exit 1
fi

# 2. 运行部署脚本
cd /root/deploy
chmod +x deploy.sh
bash deploy.sh

# 3. 显示访问地址
echo ""
echo "═════════════════════════════════════════"
echo "  🎉 部署完成"
echo "  访问 http://21.130.252.59"
echo "═════════════════════════════════════════"
```

## Step 3 · 打开浏览器访问

`http://21.130.252.59`

你会看到深黑底 + 荧光青绿的 Vo Manager，5 条种子需求 + 6 位声优。

## 🔧 如果出错

在「执行命令」里跑这些排查命令：

```bash
# 查所有容器状态
docker ps -a

# 查后端日志
docker logs vo-backend --tail 50

# 查 MySQL 日志
docker logs vo-mysql --tail 30

# 重启
cd /root/deploy && docker compose restart

# 完全重来（丢数据）
cd /root/deploy && docker compose down -v && bash deploy.sh
```
