🎙 游戏语音需求管理系统

开发交接文档
文档版本：v1.0 发布日期：2026-07-17 产品负责人：lycheelli (PM) 协作方：文案策划 · 音频策划 · 前后端工程师
📎 配套交付物：交互式原型 互动原型-语音需求管理系统.html（浏览器打开可直接操作五大模块）

产品概述

一站式游戏语音需求管理系统，覆盖「需求录入 → 台词编写 → 声优匹配 → 录制排期 → 音频归档」全流程。

五模块闭环

📋 需求汇总 → 📝 台词管理 → 🎤 声优库 → 📅 录制档期 → 🎧 VO 资产库
↑ 音频反哺需求验收，形成闭环 ↑

目标用户

角色主要职责
PM统筹版本节点、跟踪需求进度
文案策划填写文案台词（中/英）
音频策划分配声优、上传录制版台词与音频
管理员维护声优库、系统权限

数据模型

2.1 demands（需求表）

字段类型约束说明
idBIGINTPK, AUTO_INCREMENT需求 ID
versionVARCHAR(32)NOT NULL, INDEX版本号（Yang1..Yang5）
areaENUMNOT NULL, INDEX业务区域（AI / SOL / MP）
task_nameVARCHAR(128)NOT NULL任务名
descriptionTEXT需求概括
video_syncTINYINT(1)DEFAULT 0是否音画同步
req_plannerVARCHAR(32)NOT NULL需求策划
script_plannerVARCHAR(32)文案策划
en_writerVARCHAR(32)英文文案
statusENUMDEFAULT 'pending'pending / progress / done / sync

索引：idx_ver_area(version, area)、idx_status(status)

2.2 script_lines（台词表）

字段类型约束说明
idBIGINTPK
demand_idBIGINTFK, INDEX关联需求
noVARCHAR(16)NOT NULL序号（如 001）
voice_actor_idBIGINTFK, NOT NULL声优 ID（枚举，禁止自由文本）
text_cn / text_enTEXT文案台词-中/英
recorded_text_cn / recorded_text_enTEXT录制版台词-中/英
trigger_conditionVARCHAR(64)触发条件
emotionVARCHAR(32)语言情绪
gp_audio_eventVARCHAR(64)INDEXGP Audio Event 事件码
remarkVARCHAR(255)备注

2.3 voice_actors（声优库）

字段类型约束说明
idBIGINTPK
nameVARCHAR(64)NOT NULL, UNIQUE姓名（唯一）
role_typeENUMNOT NULL, INDEX干员 / 指挥官 / 路人角色
languagesVARCHAR(64)NOT NULL中文 / 英文 / 中英双语
current_scheduleVARCHAR(64)当前档期区间
availableTINYINT(1)DEFAULT 1是否可接新角色
portfolio_urlVARCHAR(255)NOT NULL必填 选角资料 URL

2.4 audio_assets（资产库）

字段类型约束说明
idBIGINTPK
script_line_idBIGINTFK, NOT NULL关联台词
languageENUM('cn','en')NOT NULL, INDEX语言
file_urlVARCHAR(255)NOT NULLCOS/OSS URL
file_name / duration / file_size元数据
version / gp_audio_event / voice_actor_idINDEX冗余便于全局检索
uploaded_byVARCHAR(32)NOT NULL上传人

2.5 script_line_history（台词变更留痕表）

🚨 红线：修改台词必须留痕。字段变更前后端拦截，diff 写入本表。必须记录：text_cn、text_en、recorded_text_cn、recorded_text_en、voice_actor_id。
字段类型说明
idBIGINTPK
script_line_idBIGINT关联台词
field_nameVARCHAR(32)变更字段名
old_value / new_valueTEXT旧值 / 新值
modified_byVARCHAR(32)修改人
modified_atDATETIME修改时间

2.6 recording_schedules（录制档期表）

字段类型说明
idBIGINTPK
record_dateDATE, INDEX录制日期
voice_actor_idBIGINT, FK声优
languageENUM('cn','en')语种
script_line_idBIGINT, FK关联台词（可空）
durationDECIMAL(4,1)时长（小时）
statusENUMpending / progress / done

核心功能规格

3.1 侧边栏树形导航

📋 需求汇总（可展开）
   ├─ Yang1 / Yang2 / Yang3 / Yang4 / Yang5
📝 台词管理（可展开）
   ├─ AI / SOL / MP
🎤 声优库（可展开）
   ├─ 干员 / 指挥官 / 路人角色
📅 录制档期（无子集，直接进入日历页）
🎧 VO 资产库（无子集，直接进入资产列表页）
  • 点击一级菜单 → 展开/收起子集，chevron 图标 90 度旋转
  • 点击子集 → 高亮 active，主内容区加载对应数据
  • URL 路由记录当前 tab（便于分享/刷新还原）

3.2 需求汇总页

  • 顶部 filter：AREA / 状态 / 策划人（动态生成）+ 搜索 + 重置
  • 表格列：任务名、AREA、需求概括、音画同步（黄标）、需求策划、文案策划、状态、操作
  • 点击「查看台词 →」跳转到台词管理页对应 AREA
  • 分页 20 条/页，大数据量启用虚拟滚动

3.3 台词管理页

🚨 硬约束：声优列必须是 <select>，options 来自声优库 API。禁止 <input type="text">。
  • URL：/scripts/:area（area ∈ AI / SOL / MP）
  • 10 列固定表头，严禁增删列
  • 可编辑列（inline，blur 时保存）：
    • 文案台词-中/英 → 角色 文案策划 / admin
    • 录制版台词-中/英 → 角色 音频策划 / admin
    • 其他 → admin
  • 保存前后端写入 script_line_history
  • 底部实时统计：每 20 词 = 1 句（中文按字符计，英文按空格分词）

3.4 声优库

🚨 硬约束：新增声优必须上传选角资料（PDF/JPG/PNG）。未上传即被拦截。
  • URL：/voice-actors/:type（type ∈ 干员/指挥官/路人角色）
  • 新增流程：先上传文件到 COS 拿 URL → 再 POST /api/voice-actors
  • Toggle「可接新角色」实时保存

3.5 录制档期（日历视图）

🚨 硬约束：必须用可视化日历组件（Ant Design Calendar / FullCalendar / react-big-calendar），不允许列表替代。
  • 月视图，每日格子展示彩色圆点：
    • 中文录制
    • 英文录制
    • 中+英
  • 点击某日 → 弹窗/侧栏展示当日排期详情
  • 支持月份切换 + 按声优/语言筛选

3.6 VO 资产库

  • URL：/assets，独立于任何需求/声优
  • 顶部 filter：声优 / GP Event / 版本 / 文件名搜索
  • 行复选框 + 全选 + 顶部「批量下载 ZIP (N)」
  • 后端流式打包 ZIP：POST /api/assets/batch-download

第三方集成

4.1 腾讯文档 API（可选）

  • 用途：将 TAPD 已收集的需求同步到 demands
  • OAuth2.0 授权 + 定时同步（30min）或触发式
  • 字段映射写在 config/tencent_doc_mapping.yaml

4.2 COS / OSS

  • 三个 bucket：voice-portfolio / voice-assets / voice-temp
  • 前端直传：后端签名凭证 → 前端上传 → 后端登记
  • 下载：后端生成 15 分钟签名 URL

4.3 通知（可选）

  • 企业微信机器人 / 邮件 SMTP
  • 触发：新排期 → 声优 + 音频；状态变更 → 需求策划；音频上传完成 → 文案

API 路由约定

Base URL: /api/v1 · 认证: Authorization: Bearer <JWT> · 响应: { code, data, message }

需求 (demands)

GET    /api/v1/demands?version=&area=&status=&planner=&keyword=&page=&size=
GET    /api/v1/demands/:id
POST   /api/v1/demands
PATCH  /api/v1/demands/:id
DELETE /api/v1/demands/:id            (admin only)

台词 (script_lines)

GET    /api/v1/script-lines?demand_id= or ?area=
GET    /api/v1/script-lines/:id
POST   /api/v1/script-lines
PATCH  /api/v1/script-lines/:id       (触发 script_line_history 留痕)
DELETE /api/v1/script-lines/:id       (admin only)
GET    /api/v1/script-lines/:id/history

声优 (voice_actors)

GET    /api/v1/voice-actors?role_type=&available=
POST   /api/v1/voice-actors           (portfolio_url 必填)
PATCH  /api/v1/voice-actors/:id
DELETE /api/v1/voice-actors/:id       (admin only)

排期 (recording_schedules)

GET    /api/v1/schedules?year=&month=&voice_actor_id=&language=
POST   /api/v1/schedules
PATCH  /api/v1/schedules/:id
DELETE /api/v1/schedules/:id

资产 (audio_assets)

GET    /api/v1/assets?voice_actor_id=&gp_audio_event=&version=&keyword=
POST   /api/v1/assets                 (script_line_id + file 二段上传)
GET    /api/v1/assets/:id/download    (302 → COS 签名 URL)
POST   /api/v1/assets/batch-download  (body: { asset_ids: [] })
DELETE /api/v1/assets/:id             (admin only)

验收标准与红线

🚨 五条红线

  1. 声优名称必须枚举化——只能 <select>，禁止 <input>
  2. 修改台词必须留痕——每次 PATCH 必须写入 script_line_history
  3. 日历视图必须可视化——不允许列表替代
  4. 新增声优必须上传选角资料——后端校验 portfolio_url 非空
  5. 权限硬约束——前端隐藏 + 后端拒绝，双重防线

验收 Checklist

  • 五模块闭环全部可用
  • 侧边栏树形导航可展开/收起，子集切换正确
  • 需求汇总按 Yang1..Yang5 正确过滤
  • 台词表格声优列为下拉框，选项来自声优库
  • 文案 / 音频角色只能编辑对应列
  • 台词编辑历史可查
  • 声优新增无选角资料时被拦截
  • 声优 toggle 开关实时保存
  • 日历显示当月所有排期，圆点颜色正确
  • 日历点击某日展示详情
  • 日历支持月份切换 + 声优/语言筛选
  • VO 资产库全局检索 + 批量下载 ZIP
  • 音频试听 / 单个下载可用
  • 单元测试覆盖率 ≥ 60%
💡 提示：点击可勾选 / 取消勾选，用于自查
